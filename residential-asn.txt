# 用户自定义住宅 ASN 名单 —— auto-select-node.ps1 启动时读取，条目会并入内置名单。
#
# 格式：每行一条  AS1234  # 备注
#       以 # 开头的整行是注释，空行忽略。
#
# 怎么收割条目：
#   脚本现在对每个节点（含被淘汰的）都打印一行  ASN : AS<号> <机构名>。
#   若你确认某个被判「机房」或「未识别」的 ASN 其实是当地的家宽运营商，
#   把它的号写到这里即可，不用改脚本，也不受脚本后续更新影响。
#
# 安全方向：这份名单只能「提升」——把某个 ASN 判为住宅。
#   写错一个不存在的号是无害的（永远匹配不上）；
#   唯一危险的方向是把一个真正的主机商 ASN 写进来，那会让它免于归属淘汰、
#   并在 -PreferResidential 下被排到最前。加之前请确认它确实卖家庭宽带。
#
# 注：ip-api 自己的 hosting=true 判定在更早的关卡就已经淘汰了大机房，
#     所以这份名单的影响范围仅限于「ip-api 没标记为机房」的那批节点。

# 示例（已内置，无需重复添加）：
# AS3462   # TW 中华电信 HiNet
